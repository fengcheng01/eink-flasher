使用注意事项：
  1. 地址选择：通常从源码编译出的 firmware.bin 属于 App 分区，选择默认的 0x10000 烧录即可；若是打包好的合并完整镜像（含 bootloader 与分区表），请选择 0x0。
  2. Metalio（ESP32-S31）：连接后自动识别并进入 ROM 无 stub 模式，按所选波特率自动提速（推荐 921600，失败自动回退），写入期间请勿断开。完整镜像选 0x0；保留数据升级选 0x80000，且必须确认设备已运行 PageRest Metalio v1，否则设备无法启动；烧录后若停在下载模式或黑屏，请物理关机再开机。
  3. 串口进入：如点击烧录后卡在 Connecting...，请长按墨水屏的 Boot 按键插线，或按住 Boot 键点按一下 Reset 键强制进入下载模式。
  4. 安全与隐私：固件读取与串口通信均在浏览器端本地完成（基于 Web Serial API），不会将固件上传至任何第三方服务器。
